## In my words

Hi, i want to create an online tool. Name: GHG Reduction Roadmap. Lets start with a MVP and add more features later. 
It is a waterfall start, that starts with the baseyear. then all the measures. The Actual, the Gap and the Target are calculated. Formula is described in the excel. 
The Scope stands for Scope 1, 2 or 3 emissions. Add this as a filter (Scope 1, Scope 2, Scope 3). Scope 3 is empty for now. Business is another filter. Scope 3 category is another filter, but currently empty.
The standard view does not differentiate graphically between the different emission sources (scope, business). Add Toggles for "Show Scope 1, 2, 3", "Show Business". If these are switched on, show the emissions in a stacked way, differentiated by colour.
Some measures are stretched over several years, distribute the emissions evenly.
Done/planned: give the Done measures a darker color. Planned measures slyghtly brighter. 
all past measures between base year and actual shall be collapsable. Create another Toggle "Show detail for past measures" if this is switched off, all done measures are summed up and this entry in the chart is called "Reductions"
